# Quizy

A lightweight quiz web app built as a student frontend project. Quizy fetches multiple-choice questions from an external API, lets users submit answers, and shows the final score in a clean, simple interface.

## Tech Stack

- React (functional components + hooks)
- Vite (build tool and dev server)
- JavaScript (ES6+)
- CSS3 (custom styling)
- Open Trivia DB API (question data)
- html-entities and clsx (utility packages)

## Run Locally

```bash
npm install
npm run dev
```

## Build for Production

```bash
npm run build
```
